# 0.3.0 缓存后端审查

对象：`0.3.0-cache-primary.1`，Steam build 25480438，主武器手动拾取测试候选。
方式：源码边界检查，加上独立保留原生消费者执行生产Lua的输出；没有外部人工
审查或实机验收。`backend-review.json`固定核对过的源码和证据SHA；相关文件
变化后须重新核对。离线通过不允许重新打包旧失败版本。

## 空间槽位与销毁

构造器`0x976FE0`将2048个hash桶放在管理器起始处，空间记录数组放在
`manager+0x4000`，每条20字节；payload在`+0xE000`，每条12字节。
`0x1735280`找空槽，将槽号写入空间记录`+0x10`、cell key写入`+0x0C`。
`0x977B70`把返回槽号写入runtime区域`+0x40`，同槽payload写entity和zone。
`+0x14020`是浮点网格比例，不能当记录数量。

生产代码要求固定池布局吻合，并核对：区域槽号 = payload槽号 = 空间记录
`+0x10`，且对应key/slot仍在grid hash。坐标不再被误读为entity/zone。
负数、越界、错位、已删除/复用槽、错误实体映射均不写入。hash探测最多128步，
过长链放行，不无限遍历。

`0x977D40`这条移除路径先清除所有相关交互者的保留指针与请求结果
(`0x977E60`)，再移除grid hash、将记录key和区域槽号标为空
(`0x977EE2/0x977EE6`)。`0x978404`位置更新使用相同槽，维护坐标及hash。
其他所有移除入口没有逐一证明，故每次仍检查全部关联，不依赖先前存活状态。

## 本机身份与写入

每帧重新读取local count=1和avatar网络ID，按当前descriptor数组找到唯一
网络ID一致且owned的交互者，再核对entity hash对应行。使用descriptor
`+0x10`网络ID，不能拿`+0x0C` unit handle比较。房主拥有的其他角色不获准。
行地址和descriptor不跨帧保存。

只过滤已确认为类型1的保留目标。替代项须来自本机当前候选，区域有效、可用位
为1、排除标志为0、分数有限且大于0，符合原生类型列表和所有权模式。取非主
武器中的最高分；没有替代项则写0。原生消费者继续检查AutoInteract及请求条件。

待处理请求按原生`row+0x820 == game+0x3483C4C`哨兵判断；已有请求时不改
目标或结果。结果其他字节可保留旧上下文/时间，不强制全0，避免过滤永远被
残留字节抑制。依据`0x9A34F5/0x9A35D9`。

写入前重新解析角色和两个目标，要求本机整行未改变，并回读本次验证涉及字段。
只向对齐、已提交、私有RW数据页的本机行首8字节执行一次当前进程
WriteProcessMemory，检查预期值、返回字节数和回读。所有游戏读取经RPM，
不直接解引用游戏地址。写入失败停止后端；可切换开关或重新进入任务后再启用。
没有代码页开放、原生函数指针调用、跳板、可执行页分配或动态展开表。

## 顺序、关闭与独立消费者核对

先前53条证据给出正常帧：Lua全局update → 游戏插件 → 角色手动交互 →
原生候选刷新。本版在共享guard的after中执行，下层Lua返回后再次确认任务
状态并处理缓存。OFF、暂停、舰船及shutdown停止写入；下一次原生刷新恢复
正常选择。不回写上一条命、上一帧或数组压缩前保存的裸指针。

`test_cache_integration.py`让实际生产Lua处理合成布局，再把结果交给保留的
原生查询、手动交互及可用条件消费者，在Unicorn执行。原始主武器请求变为
支援武器请求，区域0/1/7一致；无替代项不提交；OFF保留主武器请求；高位
entity的32位hash乘积与原生一致。消费者代码、其他角色和共享池不被改写。
模板解析、特殊前置处理及请求后的网络仍是模拟边界。

45条新布局指令与生产profile一致，并已对本地保留25480438代码核对。
两套真实LuaJIT运行生产后端、组合入口、实际Windows私有缓冲写入和真正
ModOptionsMenu作者API；完整门禁失败不交付ZIP。

## 未验证的范围

额外入口`0xFDAEE0`、其他mod的Lua外更新和所有网络/自动路径尚未完全证明，
可能影响过滤覆盖。这里只证明正常帧顺序和合成对象寿命边界。
旧闪退首个故障仍未定位；新后端移除共同原生代码修改机制，不等于已证实修复。
任务稳定性、真实拾取、死亡/增援及房主/客机仍待用户实机验证。
本包只提供主武器，首次默认ON、已有OFF保留。其余五项未恢复、保存值不改。
