# 功能范围与待完成工作

目标是只过滤安装者的交互候选，防止拾回支援武器时误捡同位置的其他物品。
设置页使用 ModOptionsMenu，不注册自定义按键。

| 独立选项 | 首次默认 | 当前状态 |
| --- | --- | --- |
| 地面主要武器 | 开启 | 0.3.0新缓存候选，待实机验收 |
| 队友召唤的支援武器 | 关闭 | 0.3.0暂不提供 |
| 野生/地图支援武器 | 关闭 | 0.3.0暂不提供 |
| 掉落样本瓶 | 关闭 | 0.3.0暂不提供 |
| 松散样本 | 关闭 | 0.3.0暂不提供 |
| 场景信息交互，如售货机、工具、叉车 | 关闭 | 0.3.0暂不提供 |

来源规则沿用用户确认的原始召唤来源：队友召唤的支援武器即使被本人拿起后
再丢下，仍算队友武器；本人召唤的支援武器始终应允许捡回。参考附件说明
形成的观察规则和完整实现保留在历史中，恢复时必须重新审查时机和稳定性。
来源不确定时允许拾取，不应误拦本人武器。

后续顺序：

1. 旧0.2.x全部撤回；不重复已失败的仅入口对照。普通崩溃报告并非已证实反作弊提示。
2. 0.3.0实现新数据缓存后端，只提供主武器。源码边界与独立原生消费者核对见
   [审查记录](CACHE-BACKEND-REVIEW.md)，实机稳定性、真实拾取、OFF及死亡/增援待测。
3. 在稳定基础上逐项恢复其他独立选项与来源观察，默认关闭，验证自动/手动路径、
   召唤来源、对象寿命和房主/客机边界。额外世界更新入口也仍需验证。
4. 完成对应实机验收后再发布完整六项版本。

旧设置保留，恢复可选项时应使用原有持久化 ID，不迁移 GUID 或建立第二份模组。
